사용자가 AI 분석 결과를 확인한 뒤 실제 제보를 등록한다.

초안은 DB에 저장되지 않으므로, 등록 시 제보 저장에 필요한 전체 데이터를 다시 전달한다.

### Example request

`POST /api/v1/reports`
