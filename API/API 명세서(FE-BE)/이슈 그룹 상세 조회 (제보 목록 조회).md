지도 화면에서 이슈 그룹 목록을 조회한다.

현재 위치 + 반경 조회와 지도 영역 조회를 모두 지원한다.

### Example request

`GET /api/v1/issues`

### **Headers**

| **Header** | **Type** | **Required** | **Description** |
| --- | --- | --- | --- |
| Authorization | `String` | No | `Bearer {accessToken}`. 로그인 시 사용자 관련 추가 정보 활용 가능 |

### **Query Parameters**

| **Parameter** | **Type** | **Required** | **Description** |
| --- | --- | --- | --- |
| latitude | `Decimal` | No | 기준 위치 위도 |
| longitude | `Decimal` | No | 기준 위치 경도 |
| radiusMeters | `Integer` | No | 기준 위치 주변 조회 반경 |
| swLat | `Decimal` | No | 지도 영역 남서쪽 위도 |
| swLng | `Decimal` | No | 지도 영역 남서쪽 경도 |
| neLat | `Decimal` | No | 지도 영역 북동쪽 위도 |
| neLng | `Decimal` | No | 지도 영역 북동쪽 경도 |
| categoryId | `Long` | No | 카테고리 ID |
| agencyId | `Long` | No | 기관 ID |
| status | `String` | No | 이슈 그룹 상태 |
| riskMin | `Decimal` | No | 최소 위험 점수 |
| riskMax | `Decimal` | No | 최대 위험 점수 |
| from | `String` | No | 조회 시작일 |
| to | `String` | No | 조회 종료일 |
