본인이 작성한 제보를 수정한다.

수정은 `SUBMITTED` 상태에서만 가능하며, `RECEIVED` 이후 상태에서는 수정할 수 없다.

### Example request

`PATCH /api/v1/reports/me/{reportId}`

### **Headers**

| **Header** | **Type** | **Required** | **Description** |
| --- | --- | --- | --- |
| Authorization | `String` | Yes | `Bearer {accessToken}` |
| Content-Type | `String` | Yes | `application/json` |

### **Query Parameters**

| **Parameter** | **Type** | **Required** | **Description** |
| --- | --- | --- | --- |
|   |   |   |   |

### **Path Parameters**

| **Parameter** | **Type** | **Required** | **Description** |
| --- | --- | --- | --- |
| reportId | `Long` | Yes | 수정할 제보 ID |

### Request Body

```json
{
  "title": "궁동 인근 도로 파손 수정 제보",
  "contents": {
    "who": "확인되지 않음",
    "when": "2026-06-05T15:30:00",
    "where": "대전광역시 유성구 궁동",
    "what": "도로 파손",
    "how": "도로 중앙 부분이 파손되어 차량 통행 시 위험해 보임",
    "why": "차량 파손 및 보행자 안전사고 위험이 있어 조치가 필요함",
    "summary": "궁동 인근 도로 파손으로 차량 및 보행자 안전 확인이 필요합니다."
  },
  "visibility": "PUBLIC",
  "categoryId": 12
}
```

### Request Fields

| **Field** | **Type** | **Description** |
| --- | --- | --- |
| title | `String` | 수정할 제보 제목 |
| contents | `Object` | 수정할 제보 본문 JSON |
| contents.who | `String` | 문제와 관련된 주체 |
| contents.when | `String` | 문제 발생 또는 확인 시각 |
| contents.where | `String` | 문제 발생 위치 설명 |
| contents.what | `String` | 발생한 문제 유형 또는 내용 |
| contents.how | `String` | 문제가 발생한 방식 또는 현재 상태 |
| contents.why | `String` | 문제가 위험하거나 조치가 필요한 이유 |
| contents.summary | `String` | 제보 요약 |
| visibility | `String` | 공개 범위 |
| categoryId | `Long` | 수정할 카테고리 ID |
