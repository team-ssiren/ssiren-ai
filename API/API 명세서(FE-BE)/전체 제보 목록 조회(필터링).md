공개 가능한 전체 제보 목록을 조회한다.

시민에게는 `visibility = PUBLIC` 중심의 공개 제보를 반환한다.

### Example request

`GET /api/v1/reports`

### **Headers**

| **Header** | **Type** | **Required** | **Description** |
| --- | --- | --- | --- |
| Authorization | `String` | No | `Bearer {accessToken}`. 로그인 시 사용자 관련 추가 정보 활용 가능 |

### **Query Parameters**

| **Parameter** | **Type** | **Required** | **Description** |
| --- | --- | --- | --- |
| categoryId | `Long` | No | 카테고리 ID |
| status | `String` | No | 제보 상태 |
| sido | `String` | No | 시/도 |
| sigungu | `String` | No | 시/군/구 |
| eupmyeondong | `String` | No | 읍/면/동 |
| from | `String` | No | 조회 시작일 |
| to | `String` | No | 조회 종료일 |
| page | `Integer` | No | 페이지 번호 |
| size | `Integer` | No | 페이지 크기 |
| sort | `String` | No | 정렬 기준 |
