## 하수도 역류(SEWER_BACKFLOW) 민원 배정 근거자료

### 1. 목적 및 적용 범위

본 자료는 하수도 역류 민원이 접수되었을 때 처리 기관과 담당 부서를 결정하기 위한 판단 기준과 법적 근거를 정리한 것이다.

적용 대상이 되는 "하수도 역류"는 공공하수도 또는 배수설비의 기능 저하·막힘·용량 부족 등으로 인해 하수나 오수가 정상적으로 배출되지 못하고 역류하는 현상을 의미한다.

구체적으로는 다음과 같은 경우를 포함한다.

- 도로 맨홀을 통한 오수 역류
- 공공하수관 막힘으로 인한 역류
- 우·오수관 배수 불량
- 집중호우 시 하수관 용량 부족으로 인한 역류
- 공공하수도 시설 고장으로 인한 오수 유출
- 하수관로 유지관리 미흡으로 인한 배수 장애

다만 건축물 내부 배관 고장이나 공동주택 내부 배수설비 문제는 공공하수도 관리 문제가 아닌 사유시설 관리 문제에 해당할 수 있으므로 별도 판단이 필요하다.

### 2. 배정 판단의 기본 원리

하수도 역류 민원은 "해당 시설이 누구의 관리 대상인가"를 기준으로 처리 주체를 결정한다.

도로 파손 민원이 도로관리청을 기준으로 배정되는 것처럼, 하수도 역류 민원은 「하수도법」상 공공하수도 관리 권한을 가진 자가 누구인지에 따라 처리 기관이 결정된다.

하수도법은 공공하수도의 설치·관리 주체를 공공하수도관리청으로 규정하고 있으며, 일반적으로 시장·군수·구청장이 그 권한을 가진다.

따라서 대부분의 하수도 역류 민원은 관할 시·군·구청으로 배정된다.

반면 건물 내부 배수설비 또는 공동주택 내부 배관 문제는 「하수도법」상 배수설비 관리 의무를 부담하는 건물 소유자 또는 관리주체의 책임 범위에 해당한다.

따라서 AI는 먼저 해당 신고가

- 공공하수도 문제인지
- 건물 내부 배수설비 문제인지

를 구분한 후 처리 기관을 결정해야 한다.

### 3. 관리주체 매핑표

| 구분                        | 처리 권한자                     | 실제 처리 주체    | 일반적 담당 부서             |
| --------------------------- | ------------------------------- | ----------------- | ---------------------------- |
| 공공하수관 역류             | 공공하수도관리청                | 해당 시·군·구청   | 하수과·하수행정과·하수시설과 |
| 맨홀 역류                   | 공공하수도관리청                | 해당 시·군·구청   | 하수도관리부서               |
| 우·오수관 막힘              | 공공하수도관리청                | 해당 시·군·구청   | 하수시설관리부서             |
| 공공하수도 용량 부족        | 공공하수도관리청                | 해당 시·군·구청   | 하수정비부서                 |
| 집중호우로 인한 역류        | 공공하수도관리청 + 재난관리기관 | 시·군·구청        | 하수과·재난안전과            |
| 공동주택 내부 배수설비 문제 | 관리주체                        | 아파트 관리사무소 | 시설관리부서                 |
| 건물 내부 배관 역류         | 소유자                          | 건물주·관리인     | 민간 관리주체                |
| 국가시설 내 하수시설        | 시설관리기관                    | 국가기관          | 시설관리부서                 |

부서명은 지자체 행정기구 조례에 따라 상이하며, 위 명칭은 대표적인 예시다.

실무에서는 상하수도사업본부, 하수행정과, 하수시설과, 치수과 등이 해당 업무를 담당하는 경우가 많다.

### 4. 법령·조례 근거 정리

#### 4-1. 공공하수도 관리 책임의 근거 (처리주체 결정)

하수도 역류 민원의 핵심 근거 법령은 「하수도법」이다.

하수도법 제2조는 공공하수도, 배수설비, 공공하수도관리청 등의 개념을 정의한다.

AI가 처리 기관을 결정하기 위해 가장 먼저 확인해야 하는 사항은 신고 대상 시설이 법률상 "공공하수도"인지 여부다.

하수도법 제18조는 공공하수도의 설치·관리 권한을 공공하수도관리청에게 부여한다.

공공하수도관리청은 특별시장·광역시장·특별자치시장·도지사·특별자치도지사·시장·군수 또는 구청장이며, 이 조항이 대부분의 하수도 역류 민원을 시·군·구청으로 배정하는 법적 근거가 된다.

#### 4-2. 하수관로 유지관리 책임의 근거

하수도법 제4조의4는 공공하수도관리청이 하수도정비 및 유지관리 계획을 수립하도록 규정한다.

또한 하수도법 제19조는 공공하수도의 운영·관리를 규정하고 있으며, 공공하수도관리청은 하수의 원활한 배제를 위한 유지관리 책임을 부담한다.

따라서 관로 막힘, 용량 부족, 유지관리 미흡 등으로 인해 발생한 하수도 역류는 공공하수도관리청의 관리 범위에 해당한다.

이 조항들은 역류 원인이 공공하수도 시설 문제인지 판단하는 핵심 근거가 된다.

#### 4-3. 건물 내부 배수설비와의 구분 근거

하수도법 제27조는 토지 또는 건축물의 소유자·관리자가 공공하수도에 연결되는 배수설비를 설치·관리하도록 규정한다.

따라서

- 건물 내부 배관 막힘
- 상가 내부 오수 역류
- 아파트 내부 배수설비 고장

등은 공공하수도 문제가 아니라 배수설비 관리 문제일 수 있다.

AI는 해당 조항을 근거로 "지자체 소관인지, 건물 관리주체 소관인지"를 판단해야 한다.

#### 4-4. 민원 처리 절차 및 부서 배정의 근거

민원 처리에 관한 법률 제16조는 접수한 민원이 다른 기관 소관인 경우 지체 없이 해당 기관으로 이송하도록 규정한다.

따라서 하수도 역류 민원이 잘못 접수된 경우

- 타 지자체 공공하수도 문제
- 국가기관 관리 시설 문제
- 공기업 관리 시설 문제

등은 해당 기관으로 이송할 수 있다.

기관 내부 부서 배정은 지방자치법 제125조와 각 지자체의 「행정기구 설치 조례」 및 「사무분장 규칙」에 따른다.

일반적으로 "하수도 관리", "공공하수도 운영", "하수시설 유지관리" 사무를 담당하는 부서로 배정된다.

### 5. 처리 흐름 요약

민원 접수 → 하수도 역류 여부 확인 → 발생 위치 확인(공공하수관·맨홀·우수관·건물 내부 배수설비) → 「하수도법」 제2조에 따른 공공하수도 여부 판단 → 공공하수도일 경우 「하수도법」 제18조에 따른 공공하수도관리청 확인 → 원칙적으로 관할 시·군·구청 배정 → 기관 내 사무분장 규칙에 따라 하수과·하수시설과·상하수도사업본부 등 담당 부서 배정 → 건물 내부 배수설비일 경우 관리주체 안내 → 타 기관 소관 시 민원처리법 제16조에 따라 이송
