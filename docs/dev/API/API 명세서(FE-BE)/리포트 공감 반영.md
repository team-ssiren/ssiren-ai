상황 1. 사용자가 해당 이슈 근처를 지나갈 때 알람을 통해 공감 요청

상황2. 사용자가 이슈 목록을 보다가 공감 (좋아요) 누름


사용자가 특정 제보에 대해 공감 또는 확인 반응을 등록한다.

반응은 `report_id` 기준으로 저장하며, 해당 제보가 속한 이슈 그룹의 반응 카운트도 함께 갱신한다.

### Example request

`POST /api/v1/reports/{reportId}/reactions`

### **Headers**

| **Header** | **Type** | **Required** | **Description** |
| --- | --- | --- | --- |
| Authorization | `String` | Yes | `Bearer {accessToken}` |
| Content-Type | `String` | Yes | `application/json` |

### **Query Parameters**

| **Parameter** | **Type** | **Required** | **Description** |
| --- | --- | --- | --- |
|   |   |   |   |

### **Path Parameters**

| **Parameter** | **Type** | **Required** | **Description** |
| --- | --- | --- | --- |
| reportId | `Long` | Yes | 반응을 등록할 제보 ID |

### Request Body

```json
{
  "reactionType": "YES"
}
```

### Request Fields

| **Field** | **Type** | **Description** |
| --- | --- | --- |
| reactionType | `String` | 반응 유형. `YES`, `NO`, `UNKNOWN` |
