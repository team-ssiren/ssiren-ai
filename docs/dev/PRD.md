# 요구사항 명세서

## 서비스명: 싸이렌

## 1. 서비스 개요

싸이렌은 시민이 일상에서 마주치는 위험 상황, 생활 불편, 신고하기 애매한 문제를 **사진, 텍스트, 위치 정보만으로 간편하게 제보**할 수 있는 한국형 로컬 제보 및 민원 신고 서비스이다.

기존의 안전신문고, 경찰 민원, 지자체 민원 서비스는 정식 신고 또는 민원 처리 절차에 가까워 시민에게 부담이 크다. 반면 모두의 경찰관은 신고 전 단계의 가벼운 제보를 허용하고, 동일 지역의 반복 제보를 모아 위험 신호로 판단하여 관련 기관에 전달한다.

시민에게는 주변 위험 정보를 확인할 수 있는 지도 기반 커뮤니티 역할을 제공하고, 공공기관에는 지역별 반복 민원과 위험 징후를 파악할 수 있는 예방 데이터 플랫폼 역할을 제공한다.

## 2. 기획 배경 및 문제 정의

### 2.1 해결하고자 하는 문제

| 문제 | 설명 |
| --- | --- |
| 신고 절차의 복잡함 | 시민은 불법 주정차, 도로 파손, 동물 사체, 위험 시설물 등을 어디에 신고해야 하는지 알기 어렵다. |
| 애매한 상황의 방치 | 112 신고를 하기엔 애매하지만 그냥 넘기기엔 불안한 상황들이 신고되지 않고 사라진다. |
| 반복 민원 파악의 어려움 | 같은 장소에서 비슷한 문제가 반복되어도 기관 입장에서는 통합적으로 확인하기 어렵다. |
| 지역 위험 정보 부족 | 시민은 내 주변에서 어떤 위험이나 불편이 자주 발생하는지 실시간으로 확인하기 어렵다. |

---

## 3. 서비스 목표

### 3.1 사용자 목표

시민이 복잡한 절차 없이 **사진, 텍스트, 위치 정보만으로 간단히 제보**할 수 있게 한다.

### 3.2 공공기관 목표

반복적으로 발생하는 지역 문제를 지도 기반으로 시각화하고, 제보 내용을 분석하여 적절한 처리 기관으로 자동 분류한다.

### 3.3 사회적 목표

정식 신고로 이어지지 않는 작은 위험 신호들을 모아 **생활 안전 예방 데이터**로 활용한다.

    # 12\. 사용자 시나리오
    
    ## 시나리오 1. 시민이 불법 주정차 차량을 제보하는 경우
    
    1. 사용자가 길을 걷다가 불법 주정차 차량을 발견한다.
    2. 앱에서 제보하기 버튼을 누른다.
    3. 사진을 촬영한다.
    4. “횡단보도 앞에 차가 계속 서 있어요.”라고 입력한다.
    5. 현재 위치가 자동으로 입력된다.
    6. AI가 카테고리를 “교통”으로 추천한다.
    7. 시스템이 처리 기관을 “지자체 교통과”로 추천한다.
    8. 지도에 제보 핀이 등록된다.
    9. 같은 문제를 본 시민들이 공감을 누른다.
    10. 반복 제보 기준을 넘으면 관리자 대시보드에 우선 처리 대상으로 표시된다.
    
    ---
    
    ## 시나리오 2. 도로 위 동물 사체를 제보하는 경우
    
    1. 사용자가 도로 위 동물 사체를 발견한다.
    2. 어디에 신고해야 할지 몰라 모두의 경찰관에 접속한다.
    3. 사진과 함께 “도로에 동물 사체가 있어요. 차들이 피해서 지나가고 있어 위험해요.”라고 입력한다.
    4. AI가 카테고리를 “환경 / 도로 위험”으로 분류한다.
    5. 시스템이 “지자체 청소·환경 부서” 또는 “도로관리 부서”를 추천한다.
    6. 지도에 위험 제보 핀이 등록된다.
    7. 주변 시민들은 해당 위치를 확인하고 주의할 수 있다.
    
    ---
    
    ## 시나리오 3. 신고하기 애매한 골목 불안 제보
    
    1. 사용자가 야간 귀가 중 특정 골목에서 반복적으로 불안감을 느낀다.
    2. 정식 신고는 애매하다고 판단한다.
    3. 모두의 경찰관에 “밤마다 이 골목에 조명이 어둡고 사람이 숨어 있을 것 같아 불안해요.”라고 제보한다.
    4. 유사 제보가 같은 지역에서 반복된다.
    5. 시스템은 해당 지역을 생활안전 위험 구역으로 표시한다.
    6. 경찰 또는 지자체는 순찰 강화, 조명 개선, CCTV 점검 등의 예방 조치를 검토할 수 있다.
